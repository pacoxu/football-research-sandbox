# 中国球员五大联赛首秀研究盘

更新时间：2026-07-26

排阵容页的“谁能第一个踢上五大联赛”模块是一项可复现的研究预测，不是博彩公司盘口，也不连接投注服务。

## 判定范围

- 候选范围为中国球员。
- 截止时间为 2027-06-30。
- 只计算英超、西甲、德甲、意甲和法甲当季顶级联赛正式出场。
- 首发和替补登场均计入；报名、替补席、青年或预备队、杯赛、欧战及次级联赛不计入。
- 首秀时间按比赛开球时间加正式登场分钟判定，首发以开球时间计；完全相同则并列。

## 模型

每名候选人的模型分由五项 0—100 分输入组成：

| 因素 | 权重 |
| --- | ---: |
| 一线队距离 | 35% |
| 成年正式比赛经验 | 25% |
| 五大联赛路径确定性 | 20% |
| 注册 / 出场资格 | 10% |
| 近期状态与可用性 | 10% |

候选人、“其他中国球员”和“本季无人”共同进入温度为 10 的 softmax。概率互斥且总和为 100%；公平十进制赔率为 `1 / probability`，不含博彩公司利润率。

## 数据维护

- 手工维护 `data/raw/big-five-debut-forecast.json`，每次更新追加按日期排序的快照。
- 候选人只存 `player_id`、评分、理由和该次评分的来源；姓名、生日和当前俱乐部在构建时从球员主表合并。
- 生成结果位于 `data/site/big-five-debut-forecast.json`，包含当前概率、赔率和相对上一快照的百分点变化。
- 页面每五分钟检查一次已部署的生成文件；底层证据超过七天未核验时显示“数据待复核”。这不是分秒级比赛数据流。

## 更新触发

出现以下节点时应复核评分：俱乐部官方签约或离队、一线队或梯队归属改变、联赛报名、正式出场、明确伤病、租借变化，以及影响注册或劳工资格的可靠公告。未证实转会传闻只能作为检索线索，不能单独改变评分。
